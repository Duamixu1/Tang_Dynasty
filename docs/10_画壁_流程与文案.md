# 《画壁》：一局怎么走、每一步说什么

> 写于 2026-10-27。在 `09_画壁_玩法与资产.md` 的基础上把玩法定死、把文案写全。
> 文案的唯一来源是 `web/src/data/script.json`，可读版 `06_文字.md` 由 `tools/script_doc.py` 导出；这份文档讲"为什么这样写"和流程，不重复抄全部台词。
> 和 09 相比改了三件证物（见第三节），其余照 09。

## 一、原文给了什么，游戏拿走什么

聊斋《画壁》本身就是一个完整的案子，几乎不用编：

| 原文 | 游戏里 |
|---|---|
| 孟龙潭与朱孝廉游寺，东壁画散花天女，"内一垂髫者，拈花微笑" | 回廊东壁的那幅画，E2 在这里 |
| 朱"注目久，不觉神摇意夺"，身飘飘到了壁上 | 事：他是自己心动进去的（E3 半首诗 + E4 题记） |
| 金甲使者"黑面如漆，绾锁挈槌"，来搜"下界人" | 怪。形按山海经陆吾画（虎身九尾、人面），E5 是它留下的断链 |
| 天女叫朱"急匿榻下"，朱伏在榻下，"竟不复忆身之何自来" | E6b：镜中照见榻下的人，已经忘了来路（结局 B） |
| 老僧弹壁："朱檀越何久游不归？"朱从壁上飘下 | 结局 A 的收尾 |
| "共视拈花人，螺髻翘然，不复垂髫矣" | E6a：镜中照见她已梳成螺髻（结局 A） |
| 老僧："幻由人生，贫道何能解" | 老僧看完题记后的那句话，也是全篇的题眼 |

主角"记异的书生"是原文没有的人：他是路过的人，看见、照见、记下来。原文的结论"幻由人生"他不替玩家说破，留给老僧说。

## 二、设计规则

1. **看，不打。** 动词只有走、看、问、照、比、落笔。
2. **镜子是唯一的工具。** 它同时是引导（离线索越近雾越重）、界面（右下角三个字 状・事・见）、核心机制（镜外 / 镜中配对）。每一对证物都是"眼睛看到的"配"镜子里才看得见的"，这是全篇唯一的规则，玩家第一次配对就能学会。
3. **画是门。** 状、事两个字亮了，东壁才能进去。进去之前，画中殿的门是墙；这一步就是全篇的"画面点"。
4. **不卡人。** 放错不扣东西，镜面晃一下、说"不是"；站着不动 90 秒给一句提示，150 秒再补半句"镜子会起雾"。
5. **结尾是一页图谱。** 结果卡按山海经的句式写怪：其状……其音……见则……。两个结局只差最后半句，玩家能看出自己的选择改了什么。

## 三、证物（7 件）与配对

左面 = **镜外**（眼睛看到、手里拿到的），右面 = **镜中**（要举镜才看得见的）。和 09 比，E5 / E6a / E6b 改了：09 里的"床下锁链 / 螺髻簪 / 下半首诗"三件都是实物，镜子用不上；现在镜中两件都是"照出来的"，镜外一件是实物，规则更统一。

| # | 证物 | 在哪 | 怎么拿 | 面 | 亮 |
|---|---|---|---|---|---|
| E1 | 朱生的幞头 | 回廊东壁下 | 拾起 | 镜外 | 状 |
| E2 | 壁上的人 | 东壁散花天女图 | 对壁举镜：天女身后多一个青衫书生 | 镜中 | 状 |
| E3 | 半首诗 | 孟龙潭（客房） | 第一次说话就给 | 镜外 | 事 |
| E4 | 反写的题记 | 老僧案上（僧房） | 先见过老僧才能翻；字是反的，镜中才读得顺 | 镜中 | 事 |
| E5 | 一截金链 | 画中殿门边 | 进画后拾起 | 镜外 | 见 |
| E6a | 镜中的螺髻 | 散花天女（画中殿） | 和她说话，她让你照她 | 镜中 | 见（结局 A：人归） |
| E6b | 镜中的榻下 | 画中殿的榻 | 对榻举镜：朱生伏在下面，已不记来路 | 镜中 | 见（结局 B：人留） |

| 镜外 | 镜中 | 亮 | 一句 |
|---|---|---|---|
| E1 | E2 | 状 | 幞头是他的，壁上多出来的人就是朱生 |
| E3 | E4 | 事 | 诗写到一半人就进去了，没有人拉他 |

E6a、E6b 都能拿；配哪一件决定结局，另一件会在结果卡上提一句。

## 五、一局流程（约 12 到 15 分钟）

| 幕 | 玩家做什么 | 亮 | 画面点 |
|---|---|---|---|
| 序 | 开场三行字；进寺门，镜子起雾 | | 回廊一点透视 |
| 一 | 跟着雾走到东壁下拾幞头；对壁举镜，镜中天女身后多一个人；两件放进镜里 | 状 | 镜中的人 |
| 二 | 客房见孟龙潭，拿半首诗；僧房见老僧，翻案上题记（镜中读反字）；两件放进镜里 | 事 | 反字在镜中翻正 |
| 三 | 回东壁"入画"，颜色化开，进画中殿；门槛拾断链；天女让你照她，或对榻举镜照见朱生；选一件放进镜里 | 见 | 入画那一下；镜中螺髻 / 榻下 |
| 四 | 落笔过场：使者从东壁鼓出来，书生取笔、悬腕、落，使者压回墙里成了壁画 | | 落笔定形 |
| 尾 | 图谱页 | | 结果卡，可保存 |

## 六、文案的写法

- **书生**：话最少，句子短，只说看到的和结论。不说"我觉得"。
- **孟龙潭**：急，话多半句，口语。他是玩家的"现实"：一直在画外等。
- **老僧**：每次一两句，绕开问题，最后一句给原文"幻由人生，贫僧何能解"。
- **天女**：轻，不解释，像画里的人说话。只说三次。
- **证物说明**：写看到的样子，不下结论，结论留给配对那一句。
- **结果卡**：山海经体一句 + 原文化用三行 + 一句"记异者曰"。
- 全篇不用"啦、呀、啊"，不用网络词，不用感叹号。
