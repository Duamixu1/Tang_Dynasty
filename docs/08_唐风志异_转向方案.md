# 转向方案：怪化猫的画法，唐朝的东西，聊斋 / 山海经的故事

> 写于 2026-10-23。前提：画风做法（纸、平涂、彩色描边、满铺纹样、屏幕空间纹样）照搬怪化猫，但画里的东西全部换成唐朝的；故事不再原创，从《聊斋志异》取案子，从《山海经》取怪的样子。
> 已经做出来的技术链（着色器、灰盒、逻辑层、Tripo 手 K、World Labs 全景）全部保留，换的是"皮"和"故事"。需要你拍板的三件事在最后。

## 一、为什么这个方向顺

怪化猫的纹样和构图，祖上就是唐。市松、七宝、唐草、联珠这些日本"有职文样"，是奈良时代从唐传过去的，正仓院里存的唐物（琵琶、镜、锦）上就是这些纹样。所以"浮世绘风格回唐朝"不是硬凑，是往上游走一步：**纸还是纸，线还是彩线，纹样换回它们原来的样子。**

聊斋和山海经各管一头：

| 来源 | 用来做什么 | 为什么 |
|---|---|---|
| 《聊斋志异》 | 每一个案子的故事：人、地点、执念、结局 | 短篇、单地点、有人情、有"异史氏曰"的收尾，正好是"形・真・理"的结构 |
| 《山海经》 | 怪的样子，和结尾的图谱页 | 山海经写怪的句式是固定的：**其状如 X，其音如 Y，见则 Z**。这三句正好对应形（状）、真（音 / 事）、理（见则 = 它意味着什么） |

两本书合起来是一个壳：**玩家是一个"记异的人"**，走进一个聊斋的故事，查清楚那只怪是什么、出了什么事、它放不下什么，最后在图谱上落下一页山海经体的记录。结尾卡就是这一页图谱（其状如……其音如……见则……），一张图能发出去。

## 二、画风 canon：逐项对照着换

| 要素 | 怪化猫（现在） | 唐风（换成） | 技术上要动什么 |
|---|---|---|---|
| 纸 | 揉皱的和纸，屏幕空间后期 | **壁画 / 绢本**：矿物颜料的颗粒 + 细裂纹 + 局部剥落（敦煌唐窟那种），还是屏幕空间后期 | `post.js` 换一张纸纹贴图，加一层很淡的裂纹和剥落遮罩，参数照旧 |
| 色 | 12 色，珊瑚红 / 青磁 / 藤紫为主 | 12 色，**唐三彩 + 敦煌矿物色**：土红、朱砂、石青、石绿、赭石、铅白（偏黄的白）、墨、金、三彩黄、三彩绿、三彩褐、胭脂 | 重出 `00_色板.png`，`scenes.json` 的 canon 改色名 |
| 线 | 藏青细线 | **铁线描 / 兰叶描**：赭墨色，粗细有变化（外轮廓粗、衣纹细且有顿挫） | 描边颜色改成赭墨 `#4A2C1E` 一类；粗细变化可以先用深度分级，不急 |
| 纹样 | 麻叶、市松、青海波、七宝 | **宝相花、联珠团窠、卷草（唐草）、忍冬 / 云气**，备选：鱼鳞、龟甲、菱格 | `tools/patterns.py` 重画四张可平铺图；`toon.js` 的 `PATTERN_NAMES` 和长宽比改名就行，采样逻辑不动 |
| 纹样投影 | 人物屏幕空间、建筑三平面 | 一样 | 不动 |
| 构图 | 一点透视长廊，或固定正侧 | **界画 / 手卷**：斜 45° 平行投影（《韩熙载夜宴图》《游春图》那种没有灭点的斜俯视），屋顶掀掉看屋里；长场景横向卷轴式推 | `camera_director.js` 加一种"界画机位"：正交相机 + 固定斜角；走廊机位仍可保留一点透视 |
| 画幅 | 2.39:1 | 一样，手卷本来就是横长 | 不动 |
| 字体 | Shippori Mincho / 思源宋 | 标题用**颜体或魏碑**感的字，正文仍思源宋 | 换一个标题字体 |

### 人物：唐人的"脸妆"和怪化猫是一回事

怪化猫药贩子的脸是画上去的（蓝眉、红点、唇下竖线），唐代女子的妆也是画上去的：**花钿（眉心）、斜红（太阳穴两道）、面靥（嘴角两点）、乌膏唇**。两边的画法完全一样，这是人物最容易"像"的地方。

- 女子：高髻（倭堕髻 / 双环望仙髻）、襦裙、披帛、花钿斜红。披帛是天然的"物理骨链"对象，等于药贩子的长发 + 帽带。
- 男子：幞头、圆领袍、蹀躞带。
- 主角（记异的人）：见第三节。

### 场景：换成寺和宅

大奥走廊换成**唐代寺院**（一条有壁画的回廊 + 一座殿 + 一个院子）或者**宅院**。寺院更顺，理由在第四节：第一个案子就发生在寺里，墙上有壁画，而壁画正是我们着色器最擅长的东西。

参考来源（做 canon 时逐帧截）：敦煌莫高窟唐窟（第 220、217、172 窟）、《簪花仕女图》《捣练图》《韩熙载夜宴图》、唐三彩俑、法门寺金银器、正仓院的唐物。

## 三、主角和核心道具：对照着换，机制不动

| | 怪化猫 | 唐风志异 | 说明 |
|---|---|---|---|
| 主角 | 药贩子（卖药的外人） | **记异的人**：一个游方书生，走到哪记到哪，身份照"异史氏"来 | 外人、安静、看不打，气质一样 |
| 随身大件 | 背后的药箱 | **书箧**（背后的书箱），里面是图谱 | 同样一个背后的大件，建模和挂点照旧 |
| 引导道具 | 腰间天秤，靠近线索会颤动 | **腰间铜镜**（海兽葡萄镜，唐代最标志的镜子），靠近怪的痕迹镜面起雾 / 映出别的东西 | 同样是腰上一个会响的东西，`scaleSignal` 逻辑照用 |
| 配对机制 | 天秤左右两盘，放对一对亮一个字 | **镜外 / 镜中**：左边放"亲眼看到的"，右边放"镜子里映出来的"，对上了亮一个字 | 两盘 → 两面，`put / weigh` 逻辑不动，只换界面皮 |
| 三个字 | 形・真・理 | **状・事・见**（其状如、其事、见则）或直接沿用 形・真・理 | 山海经原句是"其状 / 其音 / 见则"，"音"太窄，改"事"；要不要保留日文的 形真理 你定 |
| 最后一下 | 拔退魔之剑 | **落笔**：在图谱上写下这一页，怪随字定形、散去 | 剑柄上的脸 → 笔杆上的兽首；"妖化拔剑"过场 → "落笔定形"过场，画面是一整页山海经图谱在纸上浮现 |
| 结尾卡 | 三个字 + 一句话 | **一页图谱**：怪的画像 + "其状如……其音如……见则……" | 最适合发出去的一张图 |

现在手 K 的四个动作（待机、走、侧头、取物）全部能用；只有"拔剑三拍"要改成"落笔三拍"（取笔、悬腕、落下）。

## 四、第一个案子选哪个：三个候选

挑选的标准：单地点、十五分钟能讲完、有一件放不下的东西、有两个收尾的可能（现在的逻辑层支持两个结局）。

### 候选一：《画壁》（推荐）

朱孝廉在寺里看壁画，画里的散花天女对他笑，他就走进了画。画里过了一段日子，金甲使者来查"有没有下界的人"，天女把他藏在床下，他吓得魂飞；外面的孟龙潭发现他不见了，老僧弹壁喊"檀越何久游"，他从壁上下来。再看壁画，那个垂髫少女已经梳成了螺髻。老僧只说一句：幻由人生。

- 为什么最顺：**整个故事就发生在一面壁画上**。我们的画风本来就是"所有东西都蒙在纸上"，这个故事把这件事变成了剧情本身：走进去，画是世界；走出来，世界是画。寺院回廊 + 壁画墙，就是现在灰盒走廊的结构，换皮就行。
- 玩家：记异的人到寺里时朱孝廉刚消失，孟龙潭慌，老僧不说。
- 状：壁画上少了一个人 / 多了一个人（天女身边多了一个穿圆领袍的影子）；配"朱孝廉落在廊下的幞头"。
- 事：孟龙潭的证言（他看着朱走到壁前就没了）配老僧的证言（"幻由人生"）或配壁上的香灰脚印。
- 见：垂髫 → 螺髻（镜中照出她梳了髻）配床下的金甲使者锁链印（他躲过了）。两个结局：老僧弹壁，朱下来（他想回来）；或朱不下来（他想留）。谁的执念？**朱孝廉的**，"幻由人生"说的就是执念生幻。
- 山海经的角色：金甲使者就是"怪"，给它一个山海经的形（比如**陆吾**：人面虎身九尾，司天之九部，是守门的）。图谱页记的是它。
- 工作量：一个回廊、一个殿（画里的世界）、三个 NPC（孟龙潭、老僧、天女）、一个怪（金甲使者）、七件证物。和现在的手鞠案子是同一个尺寸。

### 候选二：《绿衣女》（最小）

书生于璟夜读，有个绿衣女子来唱歌，声音极细，第二天发现她是一只被蜘蛛网缠住的绿蜂；救下来，蜂爬到砚台上蘸墨，在桌上走出一个"谢"字飞走。

- 一个房间、两个人、一只蜂，比画壁小一半，适合当第二个案子或者先试手。
- 执念是"想被听见"。状 = 蜂（镜中）配歌声里的那句"几乎不像人"；事 = 蛛网配女子衣角的丝；见 = 砚台上的"谢"字配……结局只有一个，要硬加分支。
- 画面点：蜂在砚台上走字，一张图。

### 候选三：《宦娘》

温如春善琴，鬼女宦娘想学琴学不成，暗中撮合他和良工，留下一首《惜余春》。

- 琴声是核心：怪的痕迹靠"听"。适合做声音引导，但要出琴曲，多一条资产线。
- 人物四个（温、宦娘、良工、良工父），地点两处，超出一个案子的尺寸。先放着。

**推荐《画壁》做第一个案子**：视觉上把我们的画风变成剧情，寺院结构能复用灰盒走廊，有两个自然的结局，山海经的怪有位置。

## 五、山海经怎么用

不拿它当故事，拿它当**图鉴和怪的形体库**：

- 每个案子的怪，形体从山海经里挑一只，按它的句子画：人面兽身、几足几翼、什么颜色、什么声音。
- 结尾图谱页按山海经体写：`又东三百里，曰某山。有兽焉，其状如……，其音如……，见则……`
- 日后每多一个案子，图谱多一页。图谱本身就是游戏的"存档"和"成就"。
- 备选怪（都是形象强、画面好的）：陆吾（人面虎身九尾，守门）、帝江（无面六足四翼，混沌）、毕方（一足鸟，见则火）、夫诸（四角白鹿，见则大水）、九尾狐（青丘）、䰠（人面马身，赤首）、鹿蜀（马身白首虎纹，佩之宜子孙）。
