> 写于 2026-10-23。沿用 `04_玩法方案.md` 的壳子（探索 + 配对）和 `05_证物与机位.md` 的分区结构，把手鞠案换成《画壁》。三个字改**状・事・见**，天秤换**铜镜**（镜外 / 镜中两面），拔剑换**落笔**。

## 一、故事（按聊斋原文改成一个案子）

朱生（原文的朱孝廉）和孟龙潭游寺，看回廊壁画上的散花天女，看着看着人就没了。孟龙潭急着找人，老僧只说"幻由人生"，不肯多讲。**记异的书生**这时路过寺里，腰间的铜镜起了雾。

- **状**：画里多了一个人。朱生落在廊下的幞头，和镜中照出的壁画上多出来的青衫影子，是同一个人。
- **事**：他是自己心动走进去的。他临壁题的半首诗，和老僧案上的《画壁题记》（"观者心动则入"），说的是一回事。
- **见**：画中有守门的使者，见则人归，或见则人留。画中殿床下的金锁链一环（金甲使者来过），配天女给的螺髻簪（她放他走）或朱生在画中写完的下半首诗（他不走）。

怪是**金甲使者**，按山海经的**陆吾**画：人面虎身九尾，司天之九部，是守门的。结尾图谱页记它：

> 寺有兽焉，其状如虎而人面，九尾，金甲而锁，其音如钟，见则人归。（结局 A）
> ……见则人留，画中多一人。（结局 B）

## 七、下一步

1. 出 2D：`uv run tools/tripo_scene.py --only 15_...,16_...`（人物先，道具后），出一张检查一张，排成 `_lineup_tang.png` 看一致性。

3. 确认后 `uv run tools/tripo_gen.py --batch 1`（人物）、`--batch 2`（道具）。
4. 文字和证物表进 `script.json` / `clues.json`（`02_待办` 第 24 项）。
